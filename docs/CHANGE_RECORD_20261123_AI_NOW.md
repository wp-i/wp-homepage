# 2026-11-23 · 新增 ai-now

在羁绊天梯和 Reelink 之间增加 ai-now。复用现有的项目目录行，提供公开站点与源码两个入口。项目事实基于 [AI 资讯站第 36 版](https://ai-now-cn-261113.wp9617.chatgpt.site/) 和 [GitHub 源码](https://github.com/wp-i/ai-now)。

本地通过 lint、类型检查、6 项单元和组件测试、生产构建及预渲染检查。Chrome 1366×768、Chrome 1440×900 和 Edge 1366×768 复检共 18 项通过。首次多浏览器并行测试中，Edge 的减少动态效果截图比较曾失败，定向复检通过。正式发布沿用现有 GitHub Pages 工作流。
